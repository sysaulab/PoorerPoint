# Terminal Presentations
## Eating Markdown
### For Fun And Profit

We turn a markdown file into an animated ASCII deck.
- Headers stack into a title block
- Bullets reveal one at a time
- SPACE drives everything

## Navigation

- SPACE advances
- Left / Right rewind and fast-forward slides
- Up / Down scroll long content

# Under The Hood

Crossterm drives the terminal.
Pulldown-cmark parses the markdown.
